# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Azure Retail Lakehouse Analytics Platform.

## Dashboard File

- Retail_Lakehouse_Analytics.pbix

## Dashboard Pages

### Executive Overview

Executive-level business performance dashboard containing:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Average Delivery Days
- Late Delivery Percentage
- Revenue Trend Analysis
- Top Product Categories
- Revenue by State

---

### Sales & Product Performance

Detailed sales and product analytics including:

- Revenue by Seller State
- Orders by Payment Type
- Top Seller Performance
- Revenue Share by Category
- Average Order Value by Category

---

### Operations & Delivery Analytics

Operational performance monitoring including:

- On-Time vs Late Deliveries
- Delivery Trend Analysis
- Average Delivery Days by State
- Delivery Performance KPIs

---

### Data Engineering Monitoring

Pipeline monitoring and data quality reporting including:

- Total Pipeline Runs
- Successful Runs
- Failed Runs
- Pipeline Success Rate
- Data Quality Metrics
- Rows Processed
- Pipeline Execution Logs
- Data Quality Audit Results

## Business Value

The dashboard provides a complete view of:

- Business Performance
- Product Performance
- Customer Insights
- Operational Efficiency
- Data Quality Monitoring
- Pipeline Health Monitoring

## Technologies Used

- Power BI Desktop
- DAX
- Star Schema Data Model
- Azure Databricks
- Delta Lake
